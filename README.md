# Khaled Hatem Portfolio

Portfolio website for Khaled Hatem.

## GitHub Pages

1. Upload all files and folders in this directory to the repository root.
2. In GitHub: Settings → Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

The site entry point is `index.html`.

## Structure

- `index.html` — main website
- `assets/images/` — project/site images
- `assets/icons/` — icons
- `assets/videos/` — videos
- `assets/js/` — JavaScript files
- `assets/css/` — CSS files
- `.nojekyll` — prevents GitHub Pages from applying Jekyll processing

The current HTML is self-contained, so the asset folders are ready for future local assets without changing the GitHub Pages structure.
